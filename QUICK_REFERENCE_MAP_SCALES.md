# Quick Reference: Map Scale System

## Keyboard Controls

| Key | Action | Description |
|-----|--------|-------------|
| `M` | Toggle Map | Open/close campaign map |
| `1` | Province Scale | Detailed local (1 mile/hex) |
| `2` | Kingdom Scale | Regional travel (6 miles/hex) |
| `3` | Continent Scale | Continental overview (60 miles/hex) |
| `WASD` | Pan Camera | Move around the map |
| `Mouse Wheel` | Zoom | Zoom in/out on current scale |
| `J` | Toggle Journal | Show/hide adventure details |

## Scale Comparison Table

| Scale | Hex Size | Best For | Travel Time (per hex) | Visible Settlements |
|-------|----------|----------|----------------------|---------------------|
| **Province** | 1 mile | Daily exploration, dungeons | 20 min walk / 10 min ride | All types |
| **Kingdom** | 6 miles | Regional travel, kingdoms | 2 hrs walk / 1 hr ride | Towns, cities, forts |
| **Continent** | 60 miles | Epic journeys, world view | 3 days walk / 2 days ride | Cities, metropolises |

## Example Distances

### Starting Area (Province Scale)
- Home village to nearby dungeon: **5 hexes** = 5 miles = 1.5 hours walk
- Village to next town: **15 hexes** = 15 miles = 5 hours walk
- Typical session exploration: **10-30 hexes** = 10-30 miles

### Regional Travel (Kingdom Scale)
- Town to city: **10 hexes** = 60 miles = 2 days on foot
- Kingdom capital to border: **20 hexes** = 120 miles = 4 days on foot
- Typical adventure region: **30×30 hexes** = 180×180 miles

### Continental Journey (Continent Scale)
- Between major cities: **10 hexes** = 600 miles = 20 days on foot
- Coast to coast: **40 hexes** = 2,400 miles = 80 days on foot
- Typical continent: **50×50 hexes** = 3,000×3,000 miles

## DM Tips

### Starting Your Campaign

1. **Session 0-5**: Use **Province Scale**
   - Map a 30-mile radius around starting location
   - Add 3-5 nearby locations (villages, dungeons)
   - Keep it simple and detailed

2. **Session 6-15**: Introduce **Kingdom Scale**
   - Expand to 100-200 mile region
   - Add regional towns and cities
   - Show travel routes between settlements

3. **Session 16+**: Optional **Continent Scale**
   - Only if campaign goes epic/continental
   - Show major cities and geographical features
   - Use for grand strategy and world-building

### Location Planning by Scale

**Province Scale Locations**:
- Dungeons and adventure sites
- Small villages and hamlets
- Isolated towers, ruins
- Natural features (springs, groves)
- Hidden camps, lairs

**Kingdom Scale Locations**:
- Towns (1000+ population)
- Fortifications and castles
- Regional cities
- Major trade routes
- Territorial boundaries

**Continent Scale Locations**:
- Capital cities (10,000+ pop)
- Major metropolises
- Legendary landmarks
- National borders
- Climate/biome transitions

### Creating Believable Geography

**Province Scale** (1 mile hexes):
- 1 day's travel = ~24 hexes (24 miles)
- A small barony = ~30-50 hexes radius
- Typical dungeon: 5-10 hexes from town

**Kingdom Scale** (6 mile hexes):
- 1 day's travel = ~4 hexes (24 miles)
- A duchy or county = ~20-40 hexes radius
- Distance between towns: 5-15 hexes

**Continent Scale** (60 mile hexes):
- 1 day's travel = ~0.4 hexes (24 miles)
- A kingdom = ~10-30 hexes radius
- Distance between capitals: 10-50 hexes

### Visual Indicators

- **Gold Star**: Home base (your starting location)
- **Large markers**: Cities and metropolises (zoom in for names)
- **Medium markers**: Towns, forts, castles
- **Small markers**: Villages, hamlets (only visible at province scale)
- **White border**: Major cities (visible at multiple scales)
- **Shadow effect**: All locations have depth shadows

## Common Use Cases

### Planning a Journey

1. Open map with `M`
2. Switch to **Kingdom Scale** (`2`)
3. Identify starting and destination cities
4. Count hexes between them
5. Calculate: Distance = hexes × 6 miles
6. Estimate travel time based on pace

**Example**: Phandalin to Neverwinter
- Distance: 15 hexes at kingdom scale
- Miles: 15 × 6 = 90 miles
- Travel time: 90 ÷ 24 = 3.75 days (4 days on foot)

### Exploring Local Area

1. Open map with `M`
2. Switch to **Province Scale** (`1`)
3. See all nearby locations in detail
4. Dungeons and villages clearly visible
5. Plan daily excursions

### World-Building

1. Start at **Province Scale** for starting area
2. Create detailed local region (30-mile radius)
3. Switch to **Kingdom Scale** to add nearby regions
4. Add major cities and regional features
5. Optionally use **Continent Scale** for grand overview

## Quick Distance Calculator

### Province Scale (1 mile/hex)
```
Distance in hexes = Distance in miles
Travel days = Distance in miles ÷ 24
```

### Kingdom Scale (6 miles/hex)
```
Distance in miles = Hexes × 6
Travel days = (Hexes × 6) ÷ 24 = Hexes ÷ 4
```

### Continent Scale (60 miles/hex)
```
Distance in miles = Hexes × 60
Travel days = (Hexes × 60) ÷ 24 = Hexes × 2.5
```

## Integration with Combat

The map scales are separate from the tactical combat grid:

- **Campaign Map**: Shows world geography (miles per hex)
- **Combat Grid**: Shows tactical positioning (5 feet per square)

When combat starts, the game automatically transitions to the 3D tactical grid view.

## Troubleshooting

**Q: I don't see my village on the kingdom map!**  
A: Villages are too small for kingdom scale. Switch to Province Scale (`1`) to see them.

**Q: How do I add a new location?**  
A: Currently done through campaign creation. Future updates will add in-game location creation.

**Q: What if my journey spans multiple scales?**  
A: Use kingdom scale for most planning. Switch to province when near destinations.

**Q: Can I zoom between scales smoothly?**  
A: No, scales are discrete (1mi, 6mi, 60mi). This follows DMG guidelines.

## Advanced: Coordinate Conversion

The system automatically converts coordinates between scales:

**Province ? Kingdom**:
```
Kingdom Coords = Province Coords ÷ 6
```

**Kingdom ? Continent**:
```
Continent Coords = Kingdom Coords ÷ 10
```

**Province ? Continent**:
```
Continent Coords = Province Coords ÷ 60
```

**Example**: A location at province coords (30, 20)
- Kingdom: (5, 3) because 30÷6=5, 20÷6=3
- Continent: (0.5, 0.33) ? (0, 0) - too small to show!

This is why small locations disappear at larger scales.
